# M0 — Fundamentos trabajados

Registro de aprendizaje, no descripción de la implementación actual.

- uv gestiona entorno, dependencias y ejecución; no sustituye Python.
  `pyproject.toml` expresa configuración/requisitos y `uv.lock` la resolución.
  Se trabajó la separación de dependencias runtime/desarrollo.
- FastAPI define rutas/handlers; Uvicorn sirve ASGI. GET, endpoint como
  método+ruta+handler, decorador de registro, HTTP 200 y serialización JSON.
- Anotaciones de tipos expresan expectativas; no crean instancias.
- `assert` expresa expectativas; tests como contratos observables.
  Diferencia entre función directa, TestClient y servidor real con curl.
- Diferencia entre fallo y warning. El desarrollador modificó `/health`, observó
  AssertionError del cuerpo con status correcto, restauró y confirmó el test verde.

No se conserva un catálogo de dependencias de aquella versión como estado actual.
