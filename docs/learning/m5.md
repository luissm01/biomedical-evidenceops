# M5 — Logging estructurado y correlación (#21)

El desarrollador confirma trabajados los conceptos y acuerda el diseño:

- Logging estructurado: eventos con campos estables que permiten buscar y
  relacionar operaciones, en lugar de depender de texto libre.
- Request ID: identificador por petición que vincula sus eventos y se devuelve
  al consumidor para facilitar el diagnóstico.
- Metadata operativa frente a contenido sensible: duración, resultado y causa
  segura aportan diagnóstico sin registrar preguntas, respuestas ni secretos.
- Contexto transversal: propagación conceptual del identificador sin añadirlo
  a todos los contratos de negocio. Esto no acredita dominio de los detalles
  de `contextvars`, ASGI o concurrencia implementados por el agente.
