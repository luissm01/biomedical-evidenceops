# M10 — Tool calling, agentes y MCP

## Interacción confirmada

El desarrollador revisó y aprobó la arquitectura de M10.1 (#56), concretando
la separación entre búsqueda compacta y consulta detallada, DeepSeek Flash como
único proveedor inicial sin razonamiento y la autorización puntual de API de
pago. Exigió dobles sin inferencias reales, distinguir timeouts efectivos del
presupuesto cooperativo de MedCPT y respaldar referencias con los resultados.

Posteriormente aceptó la implementación y autorizó commit, PR, merge y cierre
de #56. No solicitó otra inferencia ni acreditó comprensión práctica adicional.

Esto acredita decisiones y restricciones expresadas, no dominio práctico del
ciclo ni de su implementación. La generación de código/tests no acredita aprendizaje.
